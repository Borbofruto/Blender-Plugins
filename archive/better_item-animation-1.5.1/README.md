# Archived Better Item animation prototype (1.5.1)

This is a preserved development milestone, outside the supported spatial-precision runtime. Its original installable ZIP, full source and animation tests remain here. It is not loaded by Better Item 1.5.2.

Use a copy of a .blend when evaluating this prototype. To recover an existing relative clip, use this version to Bake to Native Keyframes before switching to 1.5.2. Authoring data retained by 1.5.2 is not a claim of live animation compatibility.

The archived source retains its original manifest and manual. Archived tests import `src/better_item` under this directory; run them in a separate Blender process from current-runtime tests.
